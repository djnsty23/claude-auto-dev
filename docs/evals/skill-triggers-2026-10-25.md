# Held-out skill trigger eval, 2026-10-25

Generated by `tooling/skill-trigger-eval.js report --base before441`. The cases
file and the run rows live outside this public repo, because the prompts are
mined from private transcripts. This page carries case ids and skill names only.

## Setup

- **Prompts**: 198 real user prompts from the last 30 days of transcripts, none in #441's
  tuning set (checked against its 18 prompts). Labels come from two blind Opus agents that saw only
  each skill's stated purpose (H1 and body), never a description or any eval output. A prompt both
  labelers gave to different skills keeps the second in `accept`. 98 labels are strong.
- **Arms**: `before441` is a `git archive` of 1bce1f13, the commit before #441 (48 skills, no
  cost-reconcile). `main` is 410d979f. `p4` is this PR: P1 trims plus the design-review wording.
  Skill digests: before441 1880c5558841, main 855cd84f63fa, p4 00b883c1694f.
- **Run**: `claude -p`, Opus 5.5, effort high, n=3 per case per arm (n=9 for the 11 brain, heal and
  stripe cases, whose first-pass dips needed more power), one turn, every tool but Skill
  denied by a PreToolUse hook. A hit is an expected or accepted autodev skill loaded in the first turn.
  Every row's plugin paths were read back from the init event.
- **Decision rule**: a skill is "lower than before #441" when its rate falls below `before441` with a
  one-sided Fisher exact p < 0.05.

## Limits

- First turn only. A turn that runs Bash to look around counts as a miss even when the skill would
  load on turn two, which is most of the `(none)` cells.
- `(other)` is a non-autodev skill from the host's own skills and plugins, the same in every arm.
- Seven skills have fewer than 4 cases (a11y 1, standards 1, core 2, heal 2, perf 2,
  production-radar 2, security 2): 30 days of transcripts held no defensible prompt for more.
- `rule-*` skills are not auto-loaded by design, so their first-turn rate is expected to be near 0.
- P1 left every frontmatter byte-identical, so it cannot move a first-turn rate. Its effect is
  folded into the `p4` arm rather than run as a fourth arm.
