## The can-fail sweep grades a module that is not a suite

`tooling/check-suites-can-fail.js` runs every suite with its subject stubbed
and expects each to go red. It finds the suites by listing `tooling/` for
`test-*.js`.

That pattern also matches `tooling/test-all-pool.js`, the optional worker pool
that `test-all.js` loads as a module and never runs as a suite. Run with no
arguments it exits 0, so the sweep prints a VACUOUS row for it: a red verdict
on a file that is not a suite.

Correct behaviour: the sweep's population is the runner's own suite
population, the one definition `test-all.js` and `check:coverage` already read
from `tooling/coverage-receipt.js`, plus `test-all.js` itself, which the sweep
canaries separately. A pool module beside the suites gets no row at all, and
every real suite is swept as before.
