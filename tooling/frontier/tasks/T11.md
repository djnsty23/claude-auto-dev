## Can Sonnet take the worker seat?

Workers in this repository run on Opus. Sonnet is cheaper and faster. Before anyone moves the worker
pin, we want to know whether Sonnet does this repository's own kind of work well enough.

Plan how to find out. Do not build anything: change no file but the answer file.

Write `frontier-answer.json` at the repository root:
`{"steps":[{"do":"what happens","creates":["path"],"edits":["path"],"commands":["command"]}],"risks":["one line each"]}`

- One entry per step, in order. `creates` and `edits` list the repository paths the step would add or
  change. `commands` lists what the step would run.
- `risks` names what could make the answer wrong.
- The steps' `do` and `commands` and the `risks` together are at most 8,000 characters. A longer answer fails.
