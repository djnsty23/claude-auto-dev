## The macOS leg is sometimes red on test-inbox

The macOS CI leg is occasionally red on one line of `tooling/test-inbox.js`:

```
FAIL flat cost: 38ms empty vs 151ms with 25 files
```

It fails on commits that do not touch the inbox hook or its suite, and a re-run of the failed leg goes
green. Ubuntu and Windows pass. It has never reproduced on a developer Mac, not even under heavy load,
where the empty case takes about 200ms.

Find the cause. Do not fix it: change no file but the answer file.

Write `frontier-answer.json` at the repository root:
`{"cause":{"file":"path/to/file","mechanism":"one or two sentences"},"ruledOut":["one line each"]}`

- `file` is the one file whose code is wrong.
- `mechanism` says how that code produces this failure on the macOS leg and not on the developer Mac.
  State one cause. Put any cause you considered and rejected in `ruledOut`, not in `mechanism`.
