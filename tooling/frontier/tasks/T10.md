## Ubuntu CI is red on one headless-worker case

Since #270 (94a32b3), which added `plugins/autodev-core/scripts/headless-worker.js` and its suite
`tooling/test-headless-worker.js`, every Ubuntu CI run on main has failed one case of that suite:

```
FAIL 17. the ledger file was REPLACED on every write (its identity changed), never truncated in place
     9 of 10 writes changed the file identity
```

One run read 8 of 10. Windows and macOS pass on the same commits, and the suite passes on a
developer machine. Neither the worker nor its suite has changed since #270.

Find the cause. Do not fix it: change no file but the answer file.

Write `frontier-answer.json` at the repository root:
`{"cause":{"file":"path/to/file","mechanism":"one or two sentences"},"ruledOut":["one line each"]}`

- `file` is the one file whose code is wrong.
- `mechanism` says how that code produces this failure on Ubuntu and not elsewhere. State one cause.
  Put any cause you considered and rejected in `ruledOut`, not in `mechanism`.
