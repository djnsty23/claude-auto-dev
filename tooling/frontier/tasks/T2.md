## Windows CI: two tooling scripts hang in check:entrypoints

On the windows-latest leg, `npm run check:entrypoints` fails. It probes every
`tooling/*.js` script with `--help` and gives each one 10 seconds. Two of them
run past the budget:

- `tooling/extract-plugin-types.js`
- `tooling/reap-orphan-waiters.js`

Neither treats `--help` as a request for help. Each starts its real work
instead, which on a CI machine means waiting on things that never answer.

Every script in this repo is expected to answer `--help` quickly: print a usage
line (starting with `Usage:`) that says how to run it, exit 0, and do nothing
else. Make both scripts behave that way without changing what they do when
run normally.
