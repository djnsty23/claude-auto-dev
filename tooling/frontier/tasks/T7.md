at `plugins/autodev-core/scripts/prd-states.js`, whose helpers do that. Find every place that reads the
field itself instead of going through one of those helpers, so each can be audited.

List every file under `plugins/` and `tooling/` whose code reads the `passes` property of a prd.json story.

- Comments, prose, markdown, string literals and code that only writes the field do not count.
- Leave out `prd-states.js` itself, the `tooling/test-*.js` suites and fixture files.
- The word "passes" meaning anything other than a story's field does not count.
