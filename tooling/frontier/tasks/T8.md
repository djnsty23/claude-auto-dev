## Find the hooks that print when they have nothing to say
CLAUDE.md says a hook with nothing to say emits zero bytes. Check every hook script wired as a `command`
in `plugins/*/hooks/hooks.json` (not the `modules` entry) against that rule, on this no-op path:

- HOME, USERPROFILE and CLAUDE_CONFIG_DIR point at an empty directory. No transcript file exists.
- The working directory holds no prd.json, and is either not a git repository or a clean one.
- stdin is a well-formed JSON input for an event the hook is registered for, with its registered arguments.

List every hook script that writes at least one byte to stdout or stderr there, whatever the bytes say:
a banner, a fixed JSON reply or generic advice all count. Output only on empty or malformed input, on
`--help`, or after real work does not count. Run hooks inside a temp directory, but only read
`agent-browser-cleanup.js`: it ends browser processes.

Write `frontier-answer.json` at the repository root:
`{"items":[{"path":"plugins/x/hooks/y.js","why":"one line: the event and what it prints"}]}`
