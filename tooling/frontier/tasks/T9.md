## Review PLAN.md

`PLAN.md` at the repository root is a plan for a change nobody has built yet: an `archive` command for
`plugins/autodev-core/scripts/unattended-worker.js`. Its sections are S1 to S8. Review PLAN.md as the
last reviewer before it goes to implementation. Check its claims against the code it depends on, and
report only what is wrong or missing.

Write `frontier-answer.json` at the repository root:
`{"findings":[{"section":"S3","severity":"blocker|major|minor","claim":"one or two sentences"}]}`

- `section` is the one section where the problem sits.
- `blocker`: built as written, the change would lose data, strand work or break a running system.
  `major`: a real defect short of that. `minor`: everything else.
- One finding per problem. Mark a blocker only when the claim says how it fails.
