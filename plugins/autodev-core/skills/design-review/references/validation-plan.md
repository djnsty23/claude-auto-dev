# First-stage validation

1. Start on a controlled page you own. Compare independent card rows,
   fixed-height headings and shared tracks using identical long/missing content
   at 390, 414 and 1280 CSS pixels. Exercise required-field validation, pending,
   error, retry and persisted confirmation. Keep screenshots, measurements,
   case population and source identities. This validates the mechanism only.
2. Choose one existing site with confirmed scope, audience, actual brand rules,
   approved references and a safe workflow. Access through a service provider
   is a possible route, not permission to edit the site or its customers'
   systems.
3. Measure the current journey before changing it. Record task attempts and
   completions, incomplete or erroneous submissions, follow-up messages needed
   to get useful details, staff handling time, owner rework and review cost.
   State the sample size and observation period. Keep unknown values unknown
   rather than assuming zeros.
4. Improve one cause in a small batch. Repeat the same task and failure cases,
   inspect regression captures and ask the owner to record defects caught after
   review. Keep escaped defects as regression fixtures when reproducible. Compare
   time and cost on matched work, not a self-assigned aesthetic score.
5. Better task completion is usability evidence. A lift in qualified enquiries
   or revenue needs its own measurement with attribution, and this plan
   authorises no outreach, launch or change to a customer's site.
