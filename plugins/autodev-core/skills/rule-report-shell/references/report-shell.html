A blocker names the defect in one line

The summary says what breaks and for whom, with the one fact that makes it a blocker.

  • The trace starts where the input enters, e.g. src/handler.ts:42.
  • Each bullet is one step, in the order the code runs.
  • The last bullet states the consequence the summary promised.
  • Bullets fade in about 70ms apart. Keep a card under six.
Lower severity

A warning costs precision, not correctness

Say why it is worth fixing anyway, and what the reader loses by leaving it.

  • What the current behaviour reports.
  • What it would report once fixed.
  • Why nothing is wrong today.
Question, not a defect

An open question gets its own card

State the assumption the answer depends on, and which way it changes the verdict.

  • Where the assumption is made.
  • What would be unsafe if it turned out false.
  • Who can answer it.
